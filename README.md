# rtl-questions

מוד ל-Claude Code שמציג את שאלות הבחירה של Claude (AskUserQuestion) בסדר נכון מימין לשמאל באפליקציית הדסקטופ,
גם כשיש בשאלה עברית ומילים באנגלית או מספרים. התשובה שנבחרת חוזרת ל-Claude בסדר המקורי.

## התקנה

מתיקייה מקומית:

```
claude plugin marketplace add <נתיב לתיקייה הזו>
claude plugin install rtl-questions@rtl-questions-marketplace --scope user
```

או מ-GitHub, אחרי שמעלים את התיקייה כ-repository:

```
/plugin install rtl-questions --marketplace itaym967/rtl-questions
```
